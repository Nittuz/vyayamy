# Archived documentation

Historical review artifacts land here when they stop describing the current tree. Policy:

- **Moved, not deleted.** Point-in-time snapshots (repo reviews, architecture-as-built documents) are moved into this directory intact, with a short pointer stub left at their old path. Their content is frozen; do not edit it to match the current tree — write a new document instead.
- **The finding registry stays live.** [../specs/2026-06-10-deep-review-improvement-plan.md](../specs/2026-06-10-deep-review-improvement-plan.md) is the registry that `#NN` finding references resolve against. It remains at its original path, un-archived, until every one of its finding numbers is closed.
- Implemented feature specs and plans are archived separately under [../specs/archive/](../specs/archive/).
